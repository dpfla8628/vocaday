# 오늘의 영어 일기 — 설계

## 목적
두 사용자가 하루 3줄 내외 영어 일기를 쓰고, 서로 읽고 댓글을 달며, 부담 없는 첨삭으로 실제 실력이 느는 것.

## 사용자 흐름
1. 홈에 세 번째 카드 "오늘의 일기"(보너스 — 연속일 계산에는 안 들어감). 매일 질문 하나를 제시(예: 오늘 제일 맛있게 먹은 건?).
2. 쓰기: 최대 400자. 막히면 `(산책)`처럼 괄호 안에 한국어를 써도 된다. 입력 중에는 브라우저 기본 맞춤법 밑줄.
3. "첨삭 받기"(하루 10회 제한) → 결과:
   - 칭찬 한 줄 → 원문 대비 수정 표시(취소선/추가) → 핵심 수정 최대 3개(🔴맞춤법 🟠문법 🔵자연스럽게, 탭하면 한국어 설명, 나머지는 "더 보기") → 괄호 속 한국어의 영어 표현 → 추천 표현 1~2개.
4. "고쳐 쓰기"로 직접 다듬어 저장. 친구에게는 최신 본문과 첨삭 요약이 보인다.
5. 내 실수로 만든 복습 문제(최대 2개)가 다음 날부터 문법 복습에 섞여 나온다(블록 배열, 내가 틀렸던 형태가 오답 블록).
6. 친구 탭/일기 화면에서 둘의 일기를 날짜별로 보고 댓글.

## 첨삭 엔진 (모두 무료)
- LanguageTool 공개 API(오픈소스, 키 없음): 맞춤법·문법 오류와 위치. 실패해도 진행.
- Cloudflare Workers AI(오픈 모델): LanguageTool 결과를 힌트로 받아 JSON으로
  `{praise, corrected, edits[{from,to,type,why}], translations[{ko,en}], better[{en,ko}], practice[{s,ko,bank,tip}]}` 생성.
- 서버가 JSON을 검증(필드·길이·빈칸 1개·오답 블록 규칙)하고 통과한 것만 저장.

## 저장 (D1 kv)
- `diary:<uid>:<date>` → `{uid, date, text, review, comments[{by,text,at}], updatedAt}`
- 복습 문제는 사용자 레코드 `custom[id]`에 저장되어 기존 간격반복 큐에 합류.

## 테스트
- 첨삭 결과 검증 함수(정상/깨진 JSON/규칙 위반)를 단위 테스트.
- 실제 모델 출력 샘플 몇 개로 품질 확인 후 모델 선택.
